# CLI Blackjack

Простая CLI программка для игры в Blackjack

Референсы: 8 глава "Magical Haskell" 2025

## Сборка

1. Клонируй репозиторий.
2. Запусти `cabal build`.
3. Готово!

## Использовани

1. Запусти `cabal run` или достань бинарник из `/dist-newstyle`. (Путь до бинарника `cabal list-bin blackjack`)
2. Действуй по инструкции.
3. Профит!
